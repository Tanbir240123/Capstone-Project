
# SalesInsight

## Project Overview

SalesInsight is a sales analytics and forecasting system
designed to help small and medium-sized retail businesses
understand their sales performance.

## Project Objectives

- Import raw sales data
- Automatically clean and preprocess data
- Analyse sales, products and customers
- Forecast future sales
- Detect unusual sales changes
- Calculate an overall business performance score
- Display insights through an interactive dashboard
